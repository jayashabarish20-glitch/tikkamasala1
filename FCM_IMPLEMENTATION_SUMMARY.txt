API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

POST /api/admin/notifications/register-device
  Auth: Bearer token (admin role required)
  Body: {"token": "fcm_token_string", "platform": "web"}
  Response: 200 {"message": "Device registered successfully.", "platform": "web"}
  Errors: 400 (invalid token), 401 (not authenticated), 403 (not admin)
  Purpose: Register admin phone's FCM token with backend

GET /api/admin/notifications/devices
  Auth: Bearer token (admin role required)
  Response: 200 [{"id": 1, "platform": "web", "is_active": true, "created_at": "..."}]
  Purpose: List all registered devices for current admin

DELETE /api/admin/notifications/devices/{device_id}
  Auth: Bearer token (admin role required)
  Response: 200 {"message": "Device unregistered successfully."}
  Errors: 404 (device not found)
  Purpose: Deactivate a device from receiving notifications
